# 🏡 BinangunHomestay

Website **reservasi homestay berbasis PHP & MySQL** untuk memudahkan pengunjung melakukan pemesanan secara online.

## ✨ Fitur

* 🏠 Informasi homestay
* 📅 Booking online
* 💰 Perhitungan harga otomatis
* 💬 Konfirmasi melalui WhatsApp
* 🗺️ Google Maps
* 🔐 Dashboard Admin
* 📊 Manajemen booking & homestay

## 🛠️ Teknologi

* PHP
* MySQL
* JavaScript
* XAMPP

## 🚀 Instalasi

1. Letakkan project di `htdocs`.
2. Buat database `homestay_db`.
3. Import file `database/homestay.sql`.
4. Sesuaikan koneksi database di `config/koneksi.php`.
5. Jalankan melalui:

```text
http://localhost/homestay_booking_lengkap/
```
